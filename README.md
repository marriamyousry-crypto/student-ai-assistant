# 📖 Project Overview

Student AI Assistant is an AI-powered study assistant designed to help university students study their lecture materials.

The application allows students to upload a PDF lecture or paste study material, generate an AI-powered summary, and ask questions about the provided material.

The application uses a Streamlit interface and Hugging Face Inference Providers to generate responses.

---

# ✨ Features

- 📄 Upload lecture PDF files
- 📝 Paste study material manually
- ✨ Generate clear AI summaries
- 💬 Ask questions about the study material
- 🤖 Get AI-generated answers
- 🎓 Designed for university students
- 🖥️ Simple and user-friendly Streamlit interface
